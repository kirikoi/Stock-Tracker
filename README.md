# Stock-Tracker
I first built a stock tracker in Google Sheets using 'GOOGLEFINANCE'. While checking it, I noticed some values were wrong or unreliable. For example, JPMorgan's market cap appeared as ~$23B in some pulls, when its actual market cap is around $900B, and the value changed between refreshes.

This was a personal learning project for me to practice Python, different plugins, Google Sheets, GOOGLEFINANCE, and basic stock market concepts such as market cap, volume, P/E ratio and share counts.

What does my code do?
It uses yfinance to get current data for the stocks.
